A collection of responsive login pages created as a deep dive into **CSS Flexbox** layouts.

### Project Focus
The goal of this repository is to showcase different authentication UI designs while mastering Flexbox properties. Each page focuses on achieving perfect alignment, responsiveness, and aesthetic balance.

### Built With
- **HTML5**: Semantic structure for accessibility.
- **CSS3 (Flexbox)**: The core layout engine used for all components.


### What I Practiced
- Horizontal and vertical centering.
- Flexible form structures.
